# EODHCTSiqsxajs EODHCTSiqsxajs V3.0 中文版

`EODHCTSiqsxajs-V3.0-zh.json` 是一个统一的 SillyTavern 聊天补全（Chat Completion）预设。

默认最终回复为简体中文叙事正文。服务商返回的推理（reasoning）会被请求并与故事正文分开保存。无需使用正则表达式删除推理内容，也无需依赖完成确认句来定位故事的起始位置。


### 提示词构建顺序

1. `eod_variable_initialization` 重置所有模块变量，并恢复中速（medium）节奏作为默认回退值。
2. 已启用的功能设置器（setters）仅填充各自对应的变量。未启用的设置器保持变量为空，从而防止前一个预设或上一回合残留的旧值在无意间被重新激活。
3. 所选的节奏设置器与阶段限制器在节奏调度器（dispatcher）读取它们之前运行。
4. 推理通道契约与主任务确立通道职责与故事核心要求。
5. `<写作指导>` 分区调用独立于特定人格的叙事规则、角色自主性、关系演进、现实细节锁、信息边界与群像模块。
6. `<相关资料>` 分区包含 `<创作质料>`、`<角色设定>`、对话示例与 `<互动历史>`。
7. `<文字风格指导>` 与 `<输入和输出>` 分区仅调用分配给它们的已启用模块。
8. 算子定义调用场景矩阵与最终审计标准。最终必做事项结束规划并请求输出故事内容。

在调整提示词顺序时，请务必保持初始化器位于首位，且所有设置器位于调用器之前。`injection_position: 0` 采用列表中排列的相对顺序；`injection_order` 数值不能替代“先设置、后读取”的排列顺序。

### 故事一致性规则

用户当前的明确修正以及已确立的世界观/角色事实优先于新生成的设定。档案馆人格仅提供外层叙事框架，不会赋予角色获取叙述者专属信息的全知权限。读者意图用于指导写作技艺，但不能替用户决定行动，也不能保证主角事事顺遂。LORE 可以补充兼容的设定细节，但不得改写正典。ARC 服从于节奏契约、关系阶段、物理代价与用户自主权。REVIEW 则在同一规划流程中执行原有的审计标准。

### 附加的 OP 风格可选项

| 标识符 | 启用后的效果 | 默认状态 |
| --- | --- | --- |
| `eod_status_optional` | 在叙事正文前输出事实性场景状态代码块；未知项保持为“未知” | 关闭 |
| `eod_length_optional` | 主叙事正文约 800 汉字的软性目标，服从于场景与节奏需要 | 关闭 |
| `eod_expressions_optional` | OP 的“严格避免的表达方式”列表 | 关闭 |
| `eod_custom_writing` | 可编辑的自定义写作指导设置器 | 关闭 / 空 |
| `eod_custom_style` | 可编辑的自定义文字风格设置器 | 关闭 / 空 |

OP 的字数选项以汉字字数作为参考目标，使其近似篇幅适用于中文叙事，而非强制要求输出 800 个英文单词。启用摘要模块会请求一段约 100 汉字的简短事实摘要。OP 原预设中与合并后叙事行为无关的特定句式禁令以及默认必带的状态栏/摘要均未被强加为默认配置。

## 导入与使用指南

1. 本预设专用于Deepseek V4-pro与flash模型, 无法保证用于其它模型时的效果.
3. 若希望客户端请求并保留服务商返回的推理内容，请保持“显示思考（show_thoughts）”设置处于开启状态。对于所核查的原生 DeepSeek 后端而言，关闭预设中的这一开关并不等同于单纯在界面上隐藏思考过程。
4. 在提示词管理器（Prompt Manager）中，保持架构类条目处于开启状态。默认节奏为中速（medium）。若需更改持久化的默认节奏，请在四个 `eod_pacing_*` 选择器中仅启用一个，并关闭其余三个。若四个选择器全部关闭，初始化器会自动提供中速作为回退值；若同时启用了多个选择器，按提示词顺序排在最后的已启用设置器将生效——建议只选一个以避免歧义。
5. 按需开启可选模块。若需更改输出语言，可编辑 `output_format`，或将其关闭并在对话中直接要求特定语言。自定义写作指导与自定义风格指导为空白模板：在启用前，请先将对应条目 `setvar` 宏内第二个 `::` 之后的内容编辑为你所需的规则。
6. 若 SillyTavern 弹窗询问是否允许运行绑定在预设上的正则脚本，请审阅并允许你打算使用的脚本。推理通道与正文的分离不依赖正则权限。仅在你需要 META 行动向量包裹格式时，才在预设正则控制中单独启用可选的 META 输入包裹脚本。

所有活动的架构块与功能提示词块均使用 `user` 角色承载任务指令。标准标记负责注入原有的上下文信息。面向具体服务商的角色后处理（post-processing）仍由所选连接配置管理。

### 节奏控制与单回合临时指令

若需设置持久生效的默认节奏，请使用上文所述的四选一节奏开关。用户在消息中发出的诸如“这一轮节奏放慢一点”之类的自然语言指令，可以通过节奏调度器提示词覆写当前回合的叙事节奏；但这**不会**执行客户端宏，也不会永久改变已保存的选择器开关状态。本预设不包含也不宣称具备自动关键词路由功能。

### 可见的附加输出项

当相应模块启用时，最终内容按以下顺序排列：

1. 事实性状态栏（代码块）。
2. 主叙事正文。
3. `<Summary>...</Summary>`（剧情摘要）。
4. `<Unresolved>...</Unresolved>`（未决线索）。

未启用的附加项会被完全省略。摘要显示正则脚本可将 `<Summary>` 渲染为可折叠的 `<details>` 元素，而底层保存的消息文本中仍保留原始标签。这些附加记录绝不能包含规划过程、角色未知的秘密信息或推理转录稿。在续写（continue）模式下，模型会直接接续既有正文，不会重新输出状态栏或重复前文。

### 正则脚本行为说明

- **可选 META 输入包裹器（`eod-optional-meta-input-wrapper`）：** **仅在发送给模型的提示词视图（prompt view）中**对用户输入生效。它会避免对已经以该包裹前缀开头的输入进行重复包裹，且底层保存的用户原始消息保持不变。
- **旧版表格编辑与代管/行命令清理（`eod-hide-table-edit`、`eod-hide-legacy-proxy`）：** 同时作用于显示层与提示词视图，覆盖用户与助手消息位置。底层保存的原始文本依然可供记忆插件读取或导出使用。这些脚本仅是显示与上下文过滤器，并非数据库执行器。
- **可选摘要折叠显示（`eod-summary-details`）：** 仅作用于助手消息的显示层。
